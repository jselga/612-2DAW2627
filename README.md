# Mòdul 612 - Desenvolupament web en entorn client

Repositori amb el material, els exemples i els exercicis del mòdul 612.

## Temari

El mòdul s'organitzarà en els temes següents:

- **Tema 1 - Sintaxi i estructures del llenguatge** · 42 h
- **Tema 2 - Esdeveniments i model d'objectes del document** · 27 h
- **Tema 3 - Comunicació asíncrona client-servidor i llibreries**

### Tema 1

- [Sintaxi i estructures del llenguatge](./T1-sintaxi-i-estructures)

Inclou:

- Introducció a JavaScript
- Tipus bàsics i tipus de dades
- Operadors
- Control de flux i bucles
- Objectes
- Arrays i els seus principals mètodes
- Funcions, àmbit i context
- Prototips
- Classes ES6
- Exercicis de programació orientada a objectes

## Organització

Cada tema contindrà exemples de codi, fitxers HTML, resums teòrics i exercicis pràctics.

El repositori es completarà progressivament amb el material dels temes restants.
